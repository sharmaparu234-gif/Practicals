# Practicals

This repository contains Java programming practical exercises covering core Object-Oriented Programming (OOP) concepts and basic Java programming fundamentals.

## Contents

The repository includes practicals from 1st to 10th, each demonstrating a different Java topic:

- 1st Practical - Student marks calculation and percentage display
- 2nd Practical - Inheritance (single, multilevel, and hierarchical)
- 3rd Practical - Interfaces and hybrid inheritance
- 4th Practical - Method Overloading and Method Overriding
- 5th Practical - Simulating Operator Overloading Using Methods
- 6th Practical - Default, Parameterized, and Copy Constructors
- 7th Practical - 	Object Lifecycle and Garbage Collection
- 8th Practical - Constructor Overloading
- 9th Practical - this Keyword, Constructor Chaining, and Static Members
- 10th Practical - Encapsulation Using Getters, Setters, and Validation

## Purpose

These programs are intended for learning and practice in:

- Java classes and objects
- Constructors and methods
- Encapsulation
- Inheritance
- Interfaces
- Method overloading and object behavior
- Basic input/output and program logic

## How to run

1. Open the repository in a Java-supported IDE such as IntelliJ IDEA, Eclipse, or VS Code.
2. Open the practical file you want to run.
3. Compile and run the Java program.

Example:

```bash
javac "1st Practical"
java Main
```

Note: Some files in this repository appear to use names with spaces and may need to be renamed to a valid Java filename (for example, `Practical1.java`) before compiling in a terminal.

## Requirements

- Java JDK 8 or later
- A Java IDE or command-line compiler
